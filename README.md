## 🌟 About Me

I'm **Jaclyn "Jax" Scott**, founder of [**TheZaraAI**](https://www.thezaraai.com) — an AI automation studio focused on building agent-driven workflows and intelligent systems for real businesses.

I don't write traditional software. What I do is design, orchestrate, and ship **AI-powered automation** — the kind that handles the tedious, the repetitive, and the complex so humans can focus on the creative.

- **What I build:** AI agent pipelines, multi-step automations, and no-code/low-code workflow systems that connect AI to the tools businesses already run on
- **Currently shipping:** Autonomous email-triage agents, proposal generation systems, and multi-channel AI assistants
- **Open to collaborating on:** AI agent architecture, automation workflow design, Claude-powered integrations
- **Fun fact:** Claude Code helps me build Claude tools. It's agents all the way down.
