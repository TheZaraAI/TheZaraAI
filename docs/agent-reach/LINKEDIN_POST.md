## Publishing notes

- **Positioning:** the post and the guide are deliberately a *starter guide*, not a playbook. The
  post says explicitly that the install does not give you the revenue system. Do not add copy that
  implies the public page contains the full workflow — it does not, by design.
- **Link placement:** keep URLs in the first comment rather than the post body. Edit the guide link
  into the post after the first hour if you prefer.
- **Typography:** the post uses curly apostrophes and curly quotes (`Here’s`, `I’ll`, `let’s`,
  `“REACH”`). That is intentional. Some editors silently straighten them on paste — paste into
  LinkedIn directly from the block above and spot-check the `Here’s` line and the "REACH" line.
- **The "REACH" reply:** you are committing to a manual reply to everyone who comments. Send the
  guide URL — do not ask for an email address in exchange. The guide is genuinely free, and the
  post says so.
- **Do not add:** performance claims, reply-rate numbers, lead counts, named client verticals, or
  anything implying automated lead generation. There is no data behind those claims and the post
  loses its credibility the moment it overreaches.
- **Do not name a target vertical.** The post is written to be industry-neutral on purpose; market
  selection is part of the client work, not the public copy.
- **Credit:** the post names Panniantong in the body and links the upstream repository in the first
  comment. Keep both. Agent Reach is MIT-licensed third-party software that TheZaraAI uses — it is
  not a TheZaraAI product. Tag the author only if you can confirm the correct profile; otherwise
  leave the plain-text credit as written.
- **Hashtags:** three, at the end of the post, as written.
